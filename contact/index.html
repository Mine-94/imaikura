お問い合わせ

計算結果の誤り、制度改正の反映漏れ、リンク切れ、表示不具合など、サイトの改善につながるご連絡を受け付けています。

ご連絡いただける内容

計算結果・計算式

入力条件に対して結果が不自然、公式資料と一致しない、端数処理が違うなど。

制度・法令の更新

税率、保険料率、控除額、適用日など、改正内容の反映漏れに気づいた場合。

表示・操作の不具合

ボタンが動かない、スマートフォンで崩れる、結果が表示されないなど。

リンク・文章の誤り

公的資料へのリンク切れ、誤字、説明が分かりにくい箇所など。

連絡方法

現在は、公開されたGitHub Issuesをサイトの連絡窓口として使用しています。下のボタンから新しい報告を作成できます。

公開フォームを開く

GitHub Issuesはインターネット上に公開されます。氏名、住所、勤務先、メールアドレス、給与明細、マイナンバー、申告書類などの個人情報は記載しないでください。

報告時にあると確認しやすい情報

  • 問題があったページのURL
  • 選択した年度・地域・年齢区分などの条件
  • 個人を特定できない範囲の入力例
  • 表示された結果と、正しいと考える結果
  • 根拠となる公的資料のURL
  • 利用端末とブラウザ名（表示不具合の場合）

個別の税務・法律・労務相談について

当サイトは、個別事情に基づく税務相談、法律相談、社会保険・労務相談、申告書の作成代行には対応していません。確定的な判断が必要な場合は、税務署、自治体、年金事務所、労働基準監督署、勤務先、税理士、社会保険労務士、弁護士などへご確認ください。

確認・訂正の方針

寄せられた内容は、公的資料と計算条件を確認したうえで対応の要否を判断します。誤りが確認できた場合は、計算エンジンだけでなく、説明文、FAQ、適用日、関連ページへの影響も確認して修正します。

すべてのご連絡に個別返信できるとは限りません。また、根拠を確認できない提案や、個別相談に該当する内容には対応できない場合があります。

運営方針・個人情報の取り扱い

運営・計算基準では、情報源、公開前の確認方法、AI・自動化ツールの利用、訂正方針を説明しています。アクセス情報やCookieについてはプライバシーポリシーをご確認ください。
